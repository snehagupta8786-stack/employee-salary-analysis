Employee Salary Analysis

1. Project Objective

The objective of this project is to analyse employee salary data using SQL and understand salary distribution across different departments.

2. Tools Used

- SQL
- GitHub

3. Business Questions

This project answers the following questions:

1. What is the highest salary in the company?
2. What is the average employee salary?
3. Which employees earn more than the company's average salary?
4. What is the maximum salary in each department?
5. Which employees receive the highest salary in their respective departments?

4. SQL Concepts Used

- SELECT and WHERE
- ORDER BY
- Aggregate Functions (MAX, MIN, AVG, COUNT)
- GROUP BY
- HAVING
- INNER JOIN
- Subqueries

5. Project Findings

The analysis identifies:

- Employees with the highest salaries.
- Average salary across the company.
- Employees earning above the company average.
- Maximum salary in each department.

6. Conclusion

This project demonstrates how SQL can be used to analyse employee salary data and generate useful business insights.
